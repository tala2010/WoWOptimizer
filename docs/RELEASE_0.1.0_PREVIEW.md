# 免费开源版 0.1.0 Windows 预览包

适合希望直接运行软件、不想自行安装 Python 或编译的用户。

## 下载和使用

1. 下载 `WoWOptimizer-Windows-x64-0.1.0-preview.zip`。
2. 全部解压到一个普通文件夹。
3. 双击 `WoWOptimizer.exe`。
4. 选择游戏目录，退出游戏，再点击优化。写系统设置时按提示提权。

无需账号、激活码、付费或连接作者服务器。程序运行所需组件已经内置。包内附中文使用说明、许可证、第三方许可和对应源码快照。

这是便携 ZIP，没有独立安装向导。Windows 10/11 64 位是目标环境；本次在开发机完成启动检查，没有覆盖所有系统与客户端组合。

## 效果和范围

这是社区预览版，免费组合尚未完成实际团本效果验收，不保证提升 FPS。历史 R10 结果与 R11 待验证目标见 [真实效果](RESULTS.md)。一键优化会调整部分系统与游戏配置，执行前请阅读确认信息并保留备份。

R11 仍在 `research/r11` 中单独提供，没有默认并入桌面一键优化。当前不认识的插件版本保持原生；目录能被识别，不代表该客户端的全部优化路径都已验证。
