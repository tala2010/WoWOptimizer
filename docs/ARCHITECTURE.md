# 原理与边界

## 桌面端

`main_gui.py` 是沿用原界面的 Tkinter 入口；`optimizer_core.py` 保存目录识别、环境诊断、系统/Config 调整、恢复账本和进程守护。`free_access.py` 是无状态的永久免费接口，不生成设备指纹或访问网络。`local_release.py` 验证随源码分发的载荷哈希，再启用本地批准配置。

`tools/apply_approved_hub_release.py` 按组件预检所有文件。只在原始哈希命中时用行操作生成批准输出，并复核输出哈希；更换文件前保存不可变原件和事务日志。异常时回滚；未知版本保持原生。恢复保留对目标路径、原件、批准哈希和外部更新的检查。

本地哈希能发现意外缺失或被修改的载荷，不能抵挡已经能同时替换程序和清单的攻击者。免费版不再使用原商业签名服务器，也不把“校验成功”伪称为远端可信签名。

## 自研插件与数据路径

Hub 在批准路径中共享战斗日志、单位状态和框体输入。Details 桥保留其原生排名/分段逻辑。WA 的公共触发器可以按事件、精确法术、来源等条件，在进入用户 Lua 和光环环境前跳过确定无关的事件。未知、自定义、宽泛路径必须保持原生。

这类工作量减少可能降低 CPU 压力，但 FPS 同时受场景、GPU、暴雪引擎及其他插件影响，不能将调用次数降幅直接换算为 FPS。

## R11 研究线

R11 建立在官方 WA 5.22.0 及历次累积修改之上。公开差量由冻结候选与原版逐文件比较生成，10 个变化 Lua 文件均离线重建到相同 SHA-256。

- Equipped Items：Lua `#` 返回 UTF-8 字节数，之前把 Python 字符数当字节数，使精确过滤静默失效；R11 修正为 32,455 字节。
- SwingTimerAPI：仅完整初始化源码指纹命中时，在私有 Frame 的事件主体之前过滤能影响本人状态的 CLEU 分支。
- StatusInfo：仅完整源码指纹命中时，把 `UNIT_AURA` 改为玩家单位注册，其他事件和原生刷新保留。

没有分发上述私人光环的完整源码、导出字符串或 SavedVariables。光环版本或源码变化时应自动回原生。R11 差量依赖特定本地光环指纹；公开使用者未必拥有它们，因此不保证这些私有路径命中。

## 不再纳入默认公开安装

授权后台、支付与分销、服务器更新、私人轮转包、完整第三方插件、旧通用插件改写器均不分发。NDui/Plater 的嵌入式补丁行已从公开批准配置移除，保留空组件用于安装器 schema 兼容；空组件不标为已优化。相关未来适配应先获得可验证的许可和完整语义证据。

保留在核心中的历史诊断/实验方法不是默认开启的产品能力；依赖未分发资产的入口不能认为可用。贡献者应逐步拆分并补齐测试，不能将缺失资产包装为“全部支持”。
