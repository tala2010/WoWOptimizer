# 使用说明

1. 关闭游戏。先自行备份 `WTF/Config.wtf` 和 `Interface/AddOns`；不要将完整个人备份发到 Issues。
2. 启动程序，选择正确的游戏目录和客户端。多个客户端必须明确选择。
3. 先查看日志和确认窗口，再执行一键优化。需要写系统设置时按提示以管理员身份重启。
4. 一键优化会调整系统与游戏配置，包括阴影、视野等画面项；不适合要求所有图形选项保持原值的用户。WA 补丁本身的研究约束是保持显示与功能语义。
5. 检查结果日志。显示“原生回退”表示当前插件版本未命中固定指纹，不能算作插件优化成功。
6. 进入游戏检查原有界面、计时和点击行为。任何可见或功能差异都应视为回归，先恢复再反馈。
7. 用“恢复设置”撤销本工具有本地备份的修改。恢复只认本工具自己的备份和指纹，不应强行覆盖用户后续更新的插件。

公开版状态与备份单独位于 `%LOCALAPPDATA%/WoWOptimizerOpenSource`，不自动读取收费版的激活数据或恢复账本。任务、互斥和界面端口采用独立名称。旧版已经修改的环境应先用旧版恢复，再测试免费版；不要让两个版本同时守护同一个客户端。

免费版无需账号、机器码、激活码、购买或续费。不会自动访问授权/更新服务。反馈渠道为未来公开仓库的 Issues；当前源码不内嵌个人微信、邮箱或服务器地址。

支持情况：桌面端仅支持 Windows，目录识别覆盖多个客户端，但“能识别目录”不等于“该客户端已有经过验证的插件优化”。当前自研 Hub 的 TOC 为 38001，批准 WA 清单是历史固定文件指纹；不支持的客户端或更新后的插件不要强装。不同分支、不同插件版本和免费版新组合都还需要兼容测试。

常见问题：

- 启动提示缺少模块：用运行该程序的同一个 Python 安装 `requirements.txt`。
- 本地文件校验失败：重新获取完整公开包，不要绕过哈希检查。
- 显示部分完成：查看详细日志，保留备份；不要连续覆盖安装未知插件版本。
- 没有明显提升：这符合当前证据边界。记录同 Boss、难度、人数及前后台/锁帧情况，不能用主城 FPS 判断团本效果。

`research/r11/rebuild.py` 只接受本机已有的准确原版 WA 输入，输出 10 个变化文件到新目录；**不是完整插件安装器**，也不会修改游戏或 SavedVariables。需要完整 WA 仍应从原作者渠道获取。
