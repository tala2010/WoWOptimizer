# 待解决的问题

欢迎先认领一个能复现、能验证的小问题，避免一次提交混入大量推测性优化。

1. **公开版整合验收。** 当前保留了历史桌面端与本地批准 WA 适配，R11 是独立研究差量；应先建立干净环境里的可重复安装/恢复和显示语义检查，再决定如何合并。
2. **真实收益复现。** 收集自愿提供、脱敏后的同 Boss 对照，报告所有失败和负收益；至少同时关注平均 FPS、P99、卡顿率、错误与功能。
3. **补全场景证据。** 为记录器补充死亡/复活、锁帧与前后台证据，测量记录器自己的开销，避免测量工具污染结果。
4. **版本覆盖。** 自研插件 TOC/接口和批准指纹范围有限；新客户端、WA 更新与其他 UI 包需要逐版本验证，不应仅改 TOC 或跳过哈希检查。
5. **第三方许可。** NDui/Plater 等嵌入代码未进入公开载荷；如需恢复适配，请先记录准确上游版本、许可、来源及署名要求。私人光环须另获作者许可。
6. **纯逻辑与 Windows 写操作分离。** 拆分 600KB 核心，让目录选择、计划预览、备份和恢复可在合成环境里测试；删除依赖未分发资产的隐藏实验入口。
7. **故障恢复。** 扩充断电、写入失败、外部插件更新、损坏账本、目录链接及多客户端恢复测试。备份失败时必须停止相关写入。
8. **免费版 UI 和打包。** 保持已有紧凑布局，完善分辨率/缩放、托盘、单实例和干净机器运行测试，完善依赖锁定、可复现构建及发布校验。

暂不追求新的优化项数量，也不以调用次数或微基准的高百分比替代真实 FPS。未知输入走原生；任何显示、计时、交互或功能回归都必须先解决。
